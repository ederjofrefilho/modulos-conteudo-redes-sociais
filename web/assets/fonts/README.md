# Fontes da arte das imagens de conteúdo

Usadas só pelo renderizador de imagens (`src/lib/content-images`, `next/og`),
que exige TTF ou WOFF estático. A UI continua carregando as fontes via `next/font`.
São as fontes do design system da marca (títulos em IBM Plex Sans, rótulos em Inter).

- IBM Plex Sans (Light, Regular, SemiBold) — https://github.com/IBM/plex
- IBM Plex Mono (Regular, rótulos de dado e endereço) — https://github.com/IBM/plex
- Inter (Regular, SemiBold; subconjunto latino do @fontsource/inter) — https://github.com/rsms/inter

Todas sob a SIL Open Font License 1.1.
